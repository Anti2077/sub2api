# 账号标签与智能文件夹

智能文件夹保存筛选条件，账号属性变化后自动归类。同一账号可以同时匹配多个文件夹。文件夹只影响管理视图，调度和计费仍由账号、分组的原有配置决定。

## 操作方式

- 新建账号：在基本信息中输入标签，按回车、逗号或移开焦点添加；可直接选择已有标签。标签随 OAuth 下一步保留，也适用于 API Key、RT/SSO 批量、Codex Session/PAT 等创建入口。
- JSON 导入：为本次所有账号追加所选标签，并保留文件原有标签。
- CRS 同步：为本次新建、更新的账号追加所选标签，保留本地与来源标签；超过标签上限的账号单独报告失败。
- 编辑账号：修改或清空标签。列表名称下方展示标签。
- 批量操作：勾选账号后选择“批量管理标签”，添加或移除指定标签；其他标签保留。单次支持 1–10000 个账号，缺失账号或超出标签上限时整批回滚。

标签区分大小写，支持中文与空格，自动去掉首尾空白、空标签及重复值。每个账号最多 32 个标签，每个标签最多 128 个字符。

## 智能文件夹条件

平台、账号名称包含、标签、是否已打标签，以及更多条件中的账号类型、基础状态、调度开关、账号到期时间均可组合。不同条件使用 AND；同一条件多个选项使用 OR；标签可选择匹配全部或任意所选标签。

名称按大小写不敏感的字面子串匹配，`%` 和 `_` 没有通配符含义。基础状态指 active/inactive/error，不将临时限流视为账号基础状态。到期时间支持已到期、未来 7 天内到期、未设置到期时间。

至少设置一个条件才能保存。文件夹支持两级；上级文件夹展示自身条件和各子文件夹条件的匹配并集，账号不会重复计数。子文件夹条件独立于上级条件。列表上方的临时筛选继续与选中的文件夹范围取交集。

“未匹配任何文件夹”指没有命中任何已保存条件的账号，与“未打标签”不同。删除文件夹会删除其子文件夹规则，账号与标签保留。

## 数据与兼容

`252_smart_account_folders.sql` 将旧手动归类转换为唯一标签，例如 `生产 (#12)`，并为原文件夹保存对应的标签条件。原有父子结构与账号归类得以保留，同名文件夹不会混合。迁移可重复执行。

标签存储在 `accounts.extra.account_tags`。普通创建、编辑、备份导入及增量 Extra/Bulk Update 入口均校验标签。旧客户端更新其他 Extra 字段时，省略标签会保留现有标签；显式传入空数组可清空。

列表、分页总数、文件夹计数、筛选结果批量操作和导出均使用相同的数据库条件。原 `/admin/accounts/folders/move` 接口返回明确的操作提示，防止旧客户端继续修改已失效的手动关系。

## 本地验证

前端开发服务器启动后，打开 `/dev/smart-account-folders.html`。此页面使用真实组件和完全本地的模拟账号/API 适配器，支持新建规则、增删标签、创建账号、JSON 导入和主题切换，不发送生产请求。

数据库回归位于 `account_folder_integration_test.go` 与 `account_smart_folder_integration_test.go`，通过仓库现有 Docker 测试环境验证迁移、组合筛选、分页、重叠文件夹计数和批量回滚。前端回归覆盖标签输入法、新建/编辑、JSON 导入和账号列表操作。
