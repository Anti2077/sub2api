# Token Farm artwork provenance

These local WebP assets were generated with the configured `codex-image-gen-plus-plus` MCP using the `gpt-image-2` model, then resized/exported for the Vue farm scene. They are presentation assets only; crop state, growth timers, harvesting and rewards remain server-authoritative.

- `farm-meadow.webp` — generated from job `480a5214-b77b-442b-b143-b30ca7f6b773`; warm countryside farm background with a cottage, windmill, pond and open field.
- `farm-soil.webp`, `farm-seedling.webp`, `farm-sprout.webp`, `farm-cluster.webp`, `farm-bloom.webp`, `farm-moon.webp` — derived from sprite atlas job `3186b221-3cd5-40c1-9159-684130018b85`; soil and four token-crop growth looks.

The source PNGs are retained outside this checkout under `output/imagegen/` for review. The current farm scene uses SVG artwork with shared world coordinates. These WebP files remain as earlier iteration source assets and are not loaded by the current farm scene.
